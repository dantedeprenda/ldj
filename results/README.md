# Evidence tables

Every number in [`docs/report.md`](../docs/report.md) comes from a file here. Only summaries are
tracked; per-draw rows and predictions are regenerated by the scripts (see
[`REPRODUCE.md`](../REPRODUCE.md)). Directory names follow the experiment codes used in `configs/`.
The three tasks are **T0** routing (LLMRouterBench; T0b TwinRouterBench), **T1** content moderation
(Measuring Hate Speech) and **T2** systematic-review screening (SYNERGY).
